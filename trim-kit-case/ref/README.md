# ref/ (not in git)

`trim_case.scad` reads `ref/bambu-lab.svg` (the Bambu Lab logo) for the logo inlay on the bottom of the case.
The logo is Bambu Lab's trademark, so it is not in this repo. To build with the logo, put an SVG of it at that path.
Without it, the case builds without a logo inlay. The 3MFs in `trim-kit-case/` already include the logo.
